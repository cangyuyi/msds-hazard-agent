# 本地 OCR V2 回归结论

真实样本 12 条，V2 通过 **11/12**，结果来自 `eval/evaluation_v2.csv`，仅代表该样本集。

| V2 提升 | 证据 | 处理结果 |
|---|---|---|
| 乱码 PDF | 870 文件第 3 页本地 OCR 成功读出 5 个 CAS | 二甲苯、乙苯的 CAS 命中可自动通过；其余未命中仍转人工 |
| 扫描 PDF | MSDS 第 1 页 OCR 成功读出 `Pb` | 铅命中高毒目录，强制人工复核 |

## 剩余 Bad Case

`Sn50A` 中的 `Sn` 在成分行被 OCR 误识别为 `Sm`，因此锡未自动入表、转人工复核。

## 当前边界

本地 OCR 只辅助提取。知识表未命中、扫描件字段不完整、OCR 低置信度和高毒目录命中，均不能替代职业卫生专业判断。
